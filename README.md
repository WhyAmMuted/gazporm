> **Проект разработан в рамках программы «Газпром-класс».**  
> Комплекс решает задачу многоканального мониторинга, потоковой компрессии телеметрии с гарантией погрешности и замкнутого оптимизационного управления многоскважинным кустом газодобычи.

---

## 📌 Архитектура программного комплекса

Система построена по модульному принципу и объединяет высокоскоростные системные вычисления (Rust) с аналитическим аппаратом Data Science (Python):

```text
[ Физическая модель скважин ]
   ├── Уравнение Веймута (гидравлика шлейфа)
   ├── Эффект Джоуля-Томсона (температурная просадка)
   └── Моделирование помех КИПиА и технологических аварий
               │
               ▼
[ Edge-ядро обработки и сжатия (Rust 2024 / PyO3) ]
   ├── Каскад 1: Скользящий медианный фильтр (3 точки, O(1) RAM)
   ├── Каскад 2: Экспоненциальное сглаживание (EMA)
   └── Каскад 3: Конечный автомат Swinging Door Trending (SDT)
               │
       ┌───────┴───────┐
       ▼               ▼
[ Метрологический блок ]   [ Контур управления (APC) ]
   - Расчет MAE / RMSE / PRD   - SLSQP-оптимизатор штуцеров
   - Парето-анализ компромисса - Контроль гидратообразования
               │
               ▼
   [ АРМ Диспетчера (Streamlit Web Dashboard) ]
